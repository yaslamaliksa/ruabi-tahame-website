# روابي إنجاز تهامة — الموقع الكامل

نسخة جاهزة للرفع إلى GitHub والنشر عبر GitHub Pages، وتشمل جميع ملفات الموقع والصور والخطوط والافتتاحية التفاعلية برافعة ثلاثية الأبعاد.

## الرفع والنشر

1. فك ضغط الملف، ثم افتح مجلد `ruabi-tahame-website`.
2. أنشئ مستودعاً جديداً في GitHub.
3. من **Add file → Upload files**، ارفع **محتويات المجلد** إلى جذر المستودع، بحيث يظهر `index.html` مباشرة في الصفحة الرئيسية للمستودع. لا ترفع ملف ZIP وحده.
4. افتح **Settings → Pages**.
5. اختر **Deploy from a branch**، ثم الفرع **main** والمجلد **/(root)**، واضغط **Save**.
6. انتظر اكتمال النشر، ثم افتح الرابط الذي يظهر في صفحة Pages.

إذا استخدمت Git، ارفع المجلد كاملاً بما في ذلك الملف `.nojekyll`.

## التشغيل محلياً

افتح الطرفية داخل المجلد، ثم نفّذ:

```bash
python3 -m http.server 8000
```

افتح `http://localhost:8000` في المتصفح. استخدم خادماً محلياً بدلاً من فتح `index.html` مباشرة، لأن عرض المجسّم يعتمد على وحدات JavaScript.

## محتويات النسخة

- `index.html`: صفحات الموقع والافتتاحية.
- `styles.css` و`motion.css` و`intro.css`: التصميم والحركات.
- `app.js` و`motion.js` و`intro.js`: التنقل والتفاعلات.
- `crane-3d.js` و`crane-model.js`: عرض وبناء الرافعة ثلاثية الأبعاد.
- `assets/`: الصور والخطوط وإشعار حقوق صورة برج جدة.
- `vendor/`: مكتبة Three.js المحفوظة محلياً وترخيصها.

لا يحتاج الموقع إلى عملية بناء أو تثبيت حزم. يحتفظ بنسخة الرافعة الرسومية التفاعلية عند عدم توفر WebGL في الجهاز.
